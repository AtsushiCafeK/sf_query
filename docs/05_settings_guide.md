# 設定ガイド（管理者向け）

このツールの設定は、**ブラウザの「設定」画面から行えます**。
設定ファイル（YAML）を直接編集する必要はありません。

対象読者: 情報システム部門など、このツールを部署に導入・調整する方。
Salesforceの管理画面が触れれば十分で、プログラミングの知識は不要です。

---

## 設定画面の開き方

1. ツールを起動する

   ```bash
   poetry run python src/app.py
   ```

2. ブラウザで <http://127.0.0.1:8080> を開く
3. 画面左上の **⚙ 設定** をクリック

> 項目名や選択肢は**Salesforceから自動で読み込まれ**、プルダウンに並びます。
> API名（`bunrui__c` のような文字列）を調べて打ち込む必要はありません。

---

## 画面の構成

設定画面は4つのまとまりに分かれています。上から順に埋めれば設定が完了します。

### ① 接続設定

Salesforceへの接続に使う情報です。

| 項目 | 説明 |
|---|---|
| ログイン先 | 通常は「本番・開発組織」。検証環境なら「Sandbox」 |
| 認証方式 | 通常は **OAuth**（利用者ごとにログイン）。開発時のみ sf CLI |
| APIバージョン | `60.0` のような形式。通常は変更不要 |
| コンシューマー鍵 | 接続アプリ（外部クライアントアプリケーション）の鍵 |
| コンシューマーシークレット | **通常は空でよい**（PKCE構成では使いません） |
| コールバックURL | 接続アプリに登録したURLと**完全に一致**させる |

**鍵の入力欄について**

- 保存済みの鍵は、**画面には表示されません**（伏せ字のまま）
- 入力欄を**空のままにすると、鍵は変更されません**
- 変更したいときだけ、新しい値を入力してください

接続アプリの作り方は [OAuth 2.0 接続設定](04_oauth_setup.md) を参照してください。

### ② 対象オブジェクトと表示項目

どのデータを扱うかを決めます。

**対象オブジェクト**

接続中のSalesforce組織から一覧を取得して表示します。

組織には `取引先` `商談` などの標準オブジェクトが**千件以上**あり、そのまま並べると
目的のものを探せません。そのため既定では、**この組織で作成したカスタムオブジェクトと、
インストール済みパッケージ（TeamSpiritなど）のオブジェクトだけ**を表示します。

- **絞り込み欄** … 名前の一部を入力して絞れます。**日本語のラベルでも検索できます**（例:「稟議」）
- **標準オブジェクトも表示する** … チェックを入れると全件表示に切り替わります
- 選び直すと、下の項目一覧が読み込み直されます（この時点では保存されません）

Salesforceに接続できていない場合は、プルダウンの代わりに**入力欄**が出ます。
API名（例: `Ringi__c`）を直接入力するか、①の接続設定を整えてから戻ってきてください。

**項目の割り当て**

| 割り当て | 使われる場所 |
|---|---|
| 件名（必須） | ダウンロードしたフォルダ名、一覧表(CSV)の「件名」 |
| ステータス | 一覧表(CSV)の「ステータス」 |
| 申請日 | 一覧表(CSV)の「申請日」 |

**検索結果に表示する列**
チェックを入れた項目が、検索結果の表に列として並びます。

**並び順**
項目と向き（新しい順／古い順）を選びます。
この並び順が、**ダウンロードしたファイルの連番（001, 002…）の順序**にもなります。

**添付の形式**
通常は「Salesforce Files」。古い形式で保存されている組織のみ「旧Attachment形式」。

### ③ 検索条件（画面の絞り込み欄）

ここで追加した条件が、そのまま検索画面の入力欄になります。

**条件を1つ追加する手順**

1. **「＋ 検索条件を追加」** をクリック
2. **対象の項目** をプルダウンから選ぶ
3. これだけで、以下が**自動で入ります**
   - 入力の種類（選択リストならプルダウン、日付ならカレンダー、数値なら数値入力）
   - プルダウンの選択肢（Salesforceに登録されている値）
   - 画面に出す名前（項目のラベル）
   - 内部名
4. 必要なら「画面に出す名前」を分かりやすい表現に直す
5. **「設定を保存」**

**各欄の意味**

| 欄 | 説明 |
|---|---|
| 対象の項目 | 検索したいSalesforceの項目 |
| 画面に出す名前 | 利用者に見せる名前。日本語で自由に付けられる |
| 入力の種類 | プルダウン／カレンダー／数値 |
| 条件 | 一致・以上・以下など |
| 内部名 | プログラムが使う名前。**英数字とアンダースコアのみ** |

**プルダウンの選択肢**

- **保存値** … Salesforceに保存されている値。**変更しないでください**
- **画面表示** … 利用者に見せる文字。日本語に変えられます

> 例: 保存値 `honban` のままで、画面表示だけ「本番」にできます。

**期間で絞り込みたいとき**
同じ項目で条件を2つ作ります。

- 1つ目 … 条件を「≧ 以上」（例: 申請日（開始））
- 2つ目 … 条件を「≦ 以下」（例: 申請日（終了））

**条件を消したいとき**
その条件の右上にある **「この条件を削除」** にチェックを入れて保存します。

### ④ ダウンロード設定

| 項目 | 説明 |
|---|---|
| 保存先フォルダ | 添付ファイルの保存先 |
| ファイルの置き方 | **レコードごとのフォルダ**（整理向き）／**平置き**（印刷向き） |
| ZIPにまとめる | ダウンロード後にZIPを作る |
| 一覧表(CSV)を出力する | 印刷物と突き合わせるチェックリストを作る |

> **印刷して確認する運用なら「平置き」**をおすすめします。
> 全ファイルが1つの階層に並ぶため、まとめて選択して一括印刷できます。

## 安全のしくみ

### 保存前に必ず検証されます

**「設定を保存」を押すと、まず内容が正しいか確認されます。**
問題があれば、**設定ファイルは一切変更されず**、画面に理由が表示されます。

表示される内容の例:

- 「件名にする項目は必須です。ダウンロード時のフォルダ名と一覧表の件名に使います。」
- 「検索条件の項目名は英数字とアンダースコアで指定してください: ステータス」
- 「『分類』はプルダウンですが選択肢がありません。」
- 「検索条件の項目名が重複しています: status」

つまり、**画面から操作している限り、設定が壊れた状態になることはありません。**

### 保存のたびにバックアップされます

保存すると、**変更前の内容が自動で控えられます**。
設定画面の一番下に一覧があり、**「この時点に戻す」** で戻せます。

- 直近20世代まで保持されます（古いものから自動で削除）
- **戻す操作をする直前の状態も控えられる**ので、戻しすぎても復帰できます

---

## つまずいたときは

| 症状 | 原因と対処 |
|---|---|
| オブジェクトや項目のプルダウンが空 | Salesforceに接続できていません。①接続設定を確認し、画面右上の「Salesforceに接続」からログインしてください |
| 保存しようとすると赤いメッセージが出る | 内容に問題があります。**保存はされていません**。表示された理由を直して再度保存してください |
| 検索したら「INVALID_FIELD」と出る | 選んだ項目が対象オブジェクトに無い可能性があります。②で対象オブジェクトを選び直してください |
| 設定を変えたら検索欄が想定と違う | 設定画面下部のバックアップから、直前の状態に戻せます |
| 項目を追加したのにプルダウンに出ない | Salesforce側の変更が反映されるまで最大5分かかります。少し待って画面を再読み込みしてください |

## 補足: 設定ファイルを直接編集する場合

設定画面を使わず、`config/config.yaml` を直接編集することもできます（両方併用できます）。

**設定画面から保存したときの注意点**

手書きした日本語コメントは**基本的に保持されます**が、
**検索条件（`filters`）の各項目に書いたコメントだけは失われます**。
設定画面がその部分を書き換えるためです。

コメントを残したい場合は、`filters` の各項目の中ではなく、
セクション全体の説明として（`filters:` の前などに）書いてください。

なお、直接編集した場合も**画面を開いた時点で内容が検証され**、
問題があれば原因が画面に表示されます（500エラーにはなりません）。

設定項目の詳しい仕様は [README](../README.md) を参照してください。
