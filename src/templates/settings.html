① 接続設定

Salesforceへの接続に使う情報です。キーは保存済みでも画面には表示しません。

鍵は入力欄を空のままにすると変更されません。接続アプリの作り方は手順書（docs/04_oauth_setup.md）を参照してください。

② 対象オブジェクトと表示項目

どのオブジェクトの、どの項目を扱うかを決めます。項目はSalesforceから取得した一覧から選ぶので、API名を打ち込む必要はありません。

オブジェクトを変えると項目一覧が読み込み直されます（保存はされません）。
{% macro field_select(id, name, current) %} {% endmacro %}
{{ field_select('field_title', 'field_title', config.ringi.fields.title if config.ringi.fields else '') }}
{{ field_select('field_status', 'field_status', config.ringi.fields.status if config.ringi.fields else '') }}
{{ field_select('field_application_date', 'field_application_date', config.ringi.fields.application_date if config.ringi.fields else '') }}
{% set cur_cols = config.ringi.columns or [] %} {% if fields %} {% for f in fields %} {% endfor %} {% endif %} {% for c in cur_cols %} {% if not fields or c not in fields|map(attribute='name')|list %} {% endif %} {% endfor %}
リレーション項目（例 LastModifiedBy.Name）は一覧に出ないため、既存の設定をそのまま残す形で表示しています。
{% set ob = (config.ringi.order_by or '').split(' ') %}
{{ field_select('order_by_field', 'order_by_field', ob[0] if ob else '') }}
この並び順が、ダウンロードしたファイルの連番（001, 002…）の順序になります。

③ 検索条件（画面の絞り込み欄）

ここで追加した条件が、検索画面の入力欄になります。項目を選ぶと、型と選択肢がSalesforceの定義から自動で入ります。

{% for f in config.ringi.filters or [] %} {% set idx = loop.index0 %}
{{ f.label or f.name }}
{% for o in f.options or [] %}
{% endfor %}
保存値はSalesforceの値と一致させます。画面表示だけ日本語にできます。
{% endfor %}

④ ダウンロード設定

添付ファイルの保存先と、印刷しやすい配置を決めます。

保存前に内容を検証します。問題があれば保存せずに理由を表示します。保存時は変更前の内容を自動でバックアップします。
